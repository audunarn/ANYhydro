# Strict standard-WAMIT7 coefficient import

`anyhydro.wamit_import.import_wamit7` connects public ANYfileIO records to the
canonical dataset, owner frame transformations, stored backend and persistence.
Install the optional `anyhydro[wamit]` extra. Base/headless imports do not require
ANYfileIO, Qt, ANYsolver or Capytaine. No BEM executable is launched.

Supply authoritative full six-DOF `HydroBody` records, `HydroRequest` and an
explicit `Wamit7ImportContract`: source body order, z-up coefficient frames,
hull/lid hashes, WORLD CB coordinates, reference length, fluid properties,
request/input/executable/output hashes and convention evidence. Captured file
bytes must match those hashes. This binds declarations, not independent proof
that the files were generated by the declared executable. Sheets/generalized
modes and HAMS profiles are unsupported rather than silently reinterpreted.

The profile follows the [WAMIT7 manual, Chapter 3](https://www.wamit.com/manual7.x/html/wamit_v75manualch3.html):
period seconds, propagation heading degrees and `exp(+i omega t)` relative to
incident elevation at WORLD X=Y=0. Excitation is conjugated into canonical
`exp(-i omega t)` once. With rotational indicator `r=0/1`, multiply A by
`rho*L**(3+ri+rj)`, B additionally by omega, C by `rho*g*L**(2+ri+rj)` and
excitation per unit elevation amplitude by `rho*g*L**(2+ri)`.

Periods/headings must map bijectively to the requested grid within declared
round-to-nearest printed precision. No nearest-neighbour matching, interpolation,
phase repair, symmetrization or zero filling occurs. Every coupled entry is
required. Period-zero Ainf is imported only when explicitly requested, complete
and identified by source SHA/profile/scaling; absent limit damping is never
invented. Zero-frequency persistence is unsupported and refused. A final finite
frequency never substitutes for Ainf. Source/request rho, gravity and depth must
match; the separate HAMS radiation similarity is not applied here.

Owner `reframe_dataset` maps complete A/B/C/Ainf and complex F to WORLD axes and
the caller's reference centers. Mesh/COM/CB and incident phase origin stay in
WORLD; source-coordinate changes do not move the physical model. This map is
linear about equilibrium and does not qualify large-excursion potential flow.

The output remains **unqualified**, even when all software checks pass. The
existing excitation declaration records conventions; it does not certify source
accuracy. `.hst` can include gravity and nonsymmetric terms. Its coefficients are
transported without claiming an independently verified hydrostatic Jacobian.
Hydrostatic ownership, derivative semantics and baseline remain UNKNOWN with no
invented baseline; downstream mechanical composition refuses that missing
contract. A later scientifically adopted source declaration must resolve it.

Pinned HAMS-MREL v2.2 `.3` has contradictory polar/rectangular phases. It remains
refused; this importer supplies no HAMS producer profile, phase division or
rectangular fallback. Native HAMS acquisition completeness and W5/W7 scientific
gates remain separate requirements. Pressure/field tables, input writers and a
complete isolated production HAMS backend remain unfinished W7 work.
